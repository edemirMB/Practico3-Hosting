¿Qué es el Hosting Web?

El Hosting Web es un servicio que permite almacenar los archivos, imágenes y recursos de una página web dentro de un servidor conectado a Internet.

Gracias al hosting, los usuarios pueden acceder a una página web mediante una dirección o URL desde cualquier dispositivo conectado a Internet.

Tipos de Hosting

Hosting Compartido

Varios sitios web comparten los recursos de un mismo servidor.

VPS

Servidor privado virtual con recursos independientes.

Servidor Dedicado

Servidor completo destinado a un solo cliente.

Cloud Hosting

Utiliza recursos de infraestructura disponibles en la nube.

Cloud Computing

Cloud Computing permite utilizar recursos informáticos como servidores, almacenamiento, redes, bases de datos y aplicaciones mediante Internet.

Esto permite utilizar infraestructura tecnológica sin necesidad de adquirir físicamente todos los equipos.

Infrastructure as a Service - IaaS

IaaS significa Infrastructure as a Service. En este modelo, un proveedor Cloud proporciona recursos virtualizados como servidores, almacenamiento y redes.

El usuario puede administrar el sistema operativo, instalar servicios y configurar sus aplicaciones.

Principales proveedores Cloud

Proveedor Servicio de cómputo
Amazon Web Services Amazon EC2
Microsoft Azure Azure Virtual Machines
Google Cloud Platform Compute Engine

Implementación del Hosting Web

Para la implementación del presente práctico se utilizó GitHub Pages.

El archivo principal del sitio es index.html, el cual fue almacenado en un repositorio de GitHub y posteriormente publicado mediante GitHub Pages.

Estado del sitio: Publicado correctamente en Internet mediante HTTPS.

Administración del sitio

La página web se administra mediante Git y GitHub. Cuando se realiza una modificación en el archivo index.html, los cambios son enviados al repositorio mediante comandos Git.

Posteriormente GitHub Pages actualiza automáticamente la página publicada.
