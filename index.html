¿Qué es el Hosting Web?

El hosting web es un servicio que permite almacenar los archivos de una página web en un servidor conectado a Internet.

Tipos de Hosting

  • Hosting Compartido
  • VPS
  • Servidor Dedicado
  • Cloud Hosting

Cloud Computing

Cloud Computing permite utilizar servidores, almacenamiento, redes y otros recursos informáticos mediante Internet.

Proveedores Cloud

  1. Amazon Web Services - AWS
  2. Microsoft Azure
  3. Google Cloud Platform
  4. Oracle Cloud
  5. DigitalOcean
